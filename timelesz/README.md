# timelesz ファンダッシュボード（非公式）

タイムレス（timelesz / 旧 Sexy Zone）ファンのための、個人用・**非公式**ダッシュボード。
依存ライブラリなしの静的1ファイル（`index.html`）で、スマホでそのまま開けます。

## 使い方

`timelesz/index.html` をブラウザで開くだけ。ネット接続不要で動きます（外部リンクだけ通信）。

- スマホのホーム画面に追加すると、アプリのように使えます（Safari→共有→ホーム画面に追加）。
- ライト／ダーク切り替えは右下の🌙ボタン。
- セトリメモ・チェックリストは端末内（localStorage）に自動保存されます。

| セクション | 内容 |
|---|---|
| **メンバー名鑑** | 8人のカラー・誕生日・出身・プロフィール（タップで詳細） |

| **SNS ＆ 公式リンク** | 公式サイト・X(@OVTT_official)・Instagram・YouTube・TikTok |
| **推し診断＆認定証** | 推しをタップ→紙吹雪が舞い「推し認定証」が発行。特定メンバーには隠しメッセージが解錠される仕掛けつき🎊 |
| **予備ペンライト** | 推しの色をタップ→画面が全面発光。会場の緊急用に🔦 |

## データの更新のしかた

`index.html` 上部の `<script>` 内にある配列を編集するだけです。このページは**自動更新されない**ので、公式サイトに新しいニュースが出たら手動で反映してください（`ovtp.jp/news` を定期チェック）。

- ニュースを足す：`NEWS` 配列に `{tag, real, title, src, url, date}` を追加
- ライブ日程を足す：`TOUR_STOPS` 配列に `{city, venue, dates:["YYYY-MM-DD", ...]}` を追加
- SNSを足す：`SNS` 配列に `{t, h, url, bg, ic}` を追加
- メンバー情報の修正：`MEMBERS` 配列
- 推し診断の隠しメッセージを足す：`MEMBERS` 内の各メンバーに `secret: "本文"` を追加すると、その推しを選んだときに認定証の下に「💌 ヒミツの手紙」ボタンが出現する

## 写真について（著作権）

メンバーの実写真・グループ写真はこのページには**埋め込んでいません**。理由は2つ：

1. 公式アーティスト写真は事務所・レーベルの著作物であり、無断で複製・配布すると著作権侵害になり得るため
2. このセッションの実行環境ではネットワークポリシー上 `ovtp.jp` への直接アクセス（画像取得含む）がブロックされている

代わりに、メンバー名鑑の各カードとメンバー詳細に「📸 公式サイトで写真を見る」リンクを設置し、`ovtp.jp/timelesz/<member-slug>` の公式プロフィールページに直接飛べるようにしています。全員集合ショットは `ovtp.jp/timelesz/member`（メンバー一覧ページ）へリンクしています。

## 注意

- これは**ファンが個人的に作った非公式ページ**です。公式・所属事務所とは一切関係ありません。
- メンバー情報・ニュース・ライブ日程は**2026年7月25日時点**の公開情報を手動で収集したものです。自動更新はされないため、最新の正確な情報は必ず[公式サイト（ovtp.jp）](https://ovtp.jp/)・公式SNSで確認してください。
