# timelesz ファンダッシュボード（非公式）

タイムレス（timelesz / 旧 Sexy Zone）ファンのための、個人用・**非公式**ダッシュボード。
依存ライブラリなしの静的1ファイル（`index.html`）で、スマホでそのまま開けます。

## 使い方

`timelesz/index.html` をブラウザで開くだけ。ネット接続不要で動きます（外部リンクだけ通信）。

- スマホのホーム画面に追加すると、アプリのように使えます（Safari→共有→ホーム画面に追加）。
- ライト／ダーク切り替えは右下の🌙ボタン。
- セトリメモ・チェックリストは端末内（localStorage）に自動保存されます。

## 機能

| セクション | 内容 |
|---|---|
| **メンバー名鑑** | 8人のカラー・誕生日・出身・プロフィール（タップで詳細） |
| **誕生日カウントダウン** | 次に誕生日を迎えるメンバーを自動計算・並べ替え |
| **ニュース＆トピック** | 公式ソースへのリンク＋自由に差し込めるサンプル枠 |
| **SNS ＆ 公式リンク** | 公式サイト・X・Instagram・YouTube・タイプロ(Netflix) |
| **推し診断＆認定証** | 推しをタップ→紙吹雪が舞い「推し認定証」が発行。特定メンバーには隠しメッセージが解錠される仕掛けつき🎊 |
| **予備ペンライト** | 推しの色をタップ→画面が全面発光。会場の緊急用に🔦 |
| **セットリスト メモ** | ライブ中に曲名を記録📝（自動保存） |
| **推し活チェックリスト** | 持ち物チェック（チケット・電池・うちわ…）自動保存 |
| **今日のおみくじ** | 今日の“来る”ラッキーメンバー占い🔮 |

## データの更新のしかた

`index.html` 上部の `<script>` 内にある配列を編集するだけです。

- ニュースを足す：`NEWS` 配列に `{tag, real, title, src, url, date}` を追加
- SNSを足す：`SNS` 配列に `{t, h, url, bg, ic}` を追加
- メンバー情報の修正：`MEMBERS` 配列
- 推し診断の隠しメッセージを足す：`MEMBERS` 内の各メンバーに `secret: "本文"` を追加すると、その推しを選んだときに認定証の下に「💌 ヒミツの手紙」ボタンが出現する
