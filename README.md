# 相模湾・東京湾 釣果ダッシュボード

静岡・神奈川・東京・千葉から相模湾／東京湾に出船する遊漁船の釣果を収集・集計し、
**魚種別・船宿別・エリア別・時期別・アクセス数別**に可視化するダッシュボード。
釣果は当日の**天候・風向・潮回り**と突き合わせて分析でき、各船宿の**予約導線**を備える。

## 構成

```
data/
  boats.json               船宿マスタ（46隻: 静岡13 / 神奈川23 / 東京3 / 千葉7）
  catches/*.jsonl          釣果レコード（サンプル + 収集分）
  access/page_views.jsonl  船宿ページの月間アクセス数
scripts/
  common.py                魚種メタデータ（釣期）・月齢→潮回り計算・共通I/O
  generate_sample.py       デモ用サンプル釣果の生成（釣期/天候/潮回りを反映）
  collect_catches.py       実釣果収集フレームワーク（robots.txt遵守・レート制限つき）
  enrich_weather.py        Open-Meteo Archive API による実測気象の付与
  aggregate.py             集計 → dashboard/data.js 生成
  build_standalone.py      1ファイル版ダッシュボード生成（プレビュー共有用）
dashboard/
  index.html               ダッシュボード本体（依存ライブラリなし・静的1ページ）
  data.js                  集計済みデータ（aggregate.py が生成）
.github/workflows/
  deploy-pages.yml         GitHub Pages への公開
  collect-daily.yml        毎朝の収集→集計→コミット（JST 6:00）
```

## 使い方

```bash
python scripts/generate_sample.py   # サンプルデータ生成（デモ用）
python scripts/aggregate.py         # dashboard/data.js を生成
# dashboard/index.html をブラウザで開く（またはローカルサーバで dashboard/ を配信）
```

## ダッシュボード機能

- **KPI**: 総釣果 / 出船回数 / 出船船宿数 / 平均釣果・人
- **フィルタ**: 期間（30日/90日/半年/1年）× 湾 × 都県 × 港 × 魚種 × 船宿（全チャート連動、ランキングのバーをクリックしても絞り込み）
- **時期別**: 月別釣果推移（相模湾/東京湾の積み上げ）
- **ランキング**: 魚種別 / 船宿別 / 港別 / アクセス数別
- **コンディション分析**: 天候別・風向別・潮回り別の平均釣果／人
- **船宿一覧**: 釣り物・期間内釣果・アクセス数・予約ボタン
- ライト/ダーク両テーマ対応、各チャートにデータ表（アクセシビリティ）

## データについて（重要）

- 現在の釣果・アクセス数は**デモ用サンプルデータ**。魚種ごとの釣期、天候・風速による
  出船率と釣果変動、月齢から実計算した潮回りを反映した生成モデルで、
  実データ接続後と同じスキーマ・同じ画面で動く。
- `data/boats.json` は開発用シードデータ。`confidence: "medium"` の船宿は
  公開前に公式情報（船宿名・港・釣り物・URL）の再確認が必要。
  静岡側（熱海港・網代港・伊東港）はWeb検索で実在確認済みの船宿を収録
  （安菜丸・鈴喜丸・富士丸・森竜丸・妙法丸・村正丸・誠徳丸は公式サイトURL付き）。
- 潮回りは月齢からの簡易計算（±1日程度の誤差あり）。精度が必要なら気象庁の
  潮位表または海上保安庁の潮汐推算への切替を推奨。

## 実データ収集とコンプライアンス

`scripts/collect_catches.py` は船宿ごとの釣果ページをアダプタ方式で解析する。
`data/boats.json` の各船宿に `catch_page`（釣果ページURL）と `adapter` を追記して有効化する。

**必ず守ること:**

1. 対象サイトの**利用規約**と **robots.txt** を確認・遵守する（フレームワークが robots.txt を自動チェック）
2. リクエスト間隔は最低10秒、収集は1日1回（cron は JST 6:00）
3. 可能な限り各船宿から**掲載許諾**を得て、出典を明記する
4. 釣果データを商用サービスに使う場合は、釣割・アングラーズ等の
   **公式API/提携プログラム**の利用を優先的に検討する

気象データは [Open-Meteo](https://open-meteo.com/)（非商用無償）。商用公開時は有償プランか気象庁データへ。

## インターネット公開（GitHub Pages）

1. このブランチを `main` にマージ
2. リポジトリ **Settings → Pages → Source: GitHub Actions** を選択
3. `deploy-pages.yml` が走り、`https://<user>.github.io/fishing/` で公開される

アクセス解析を本番で使う場合は GoatCounter / Plausible / Cloudflare Web Analytics 等を
`dashboard/index.html` に組み込み、その集計値を `data/access/page_views.jsonl` に取り込む。

## 予約機能のロードマップ

| フェーズ | 内容 | 状態 |
|---|---|---|
| 1 | 予約ボタン → 公式サイト/検索結果へ誘導、クリック数をローカル計測 | ✅ 実装済み |
| 2 | 釣割・アングラーズ等の予約サイトへのアフィリエイトリンク接続 | 提携申請が必要 |
| 3 | 自前予約システム（空席管理・決済・船宿向け管理画面） | 要バックエンド（静的サイトでは不可） |
