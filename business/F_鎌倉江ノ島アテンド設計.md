## 1. ⚠️ 鎌倉高校前の現実：市が本気で対策している

**ここを知らずにガイドすると、地域の敵になる。**

### 鎌倉市が実施中の対策（実証実験）
| 対策 | 内容 |
|---|---|
| **AIカメラ** | **12台で人流解析**。次年度は6台に集約し、警備員配置と警察への情報提供に活用 |
| **交通誘導員** | **9月1日から平日にも配置**。車道・軌道内での撮影に注意喚起 |
| **看板設置** | 「車両の通行の妨げにならないように」「ポイ捨て禁止」「人の土地に勝手に立ち入らない」 |
| **🎯 公式撮影エリア** | **腰越ラッコ公園に撮影エリアを設置**し、撮影目的の観光客を誘導している |
| 多言語発信 | 日本語・英語・中国語でSNS・公式ガイドから呼びかけ |

### 💡 これは制約ではなく、**最大の差別化材料**

> 個人客は「どこで撮っていいか分からず」道路に出て怒られる。
> **あなたは市が指定した撮影エリアを知っていて、そこへ案内できる。**

```
❌ 個人客        → 道路上で撮影 → 警備員に注意される → 気まずい思い出
⭕ あなたのツアー → 公式エリアで安全に撮影 → 良い写真 + 地域に歓迎される
```

### ガイドとして徹底すること
- [ ] **軌道内・車道に絶対に立ち入らせない**
- [ ] **私有地に入らせない**（民家の敷地）
- [ ] **ゴミは全て持ち帰る**（ガイドがゴミ袋を持つ）
- [ ] **騒がない**（住宅地であることを事前に説明）
- [ ] 市の公式撮影エリアを第一候補にする

> ⭐ **茅ヶ崎在住の地元民として、ここは絶対に外さないこと。**
> 地域の評判は、長期的にこの事業の生命線になる。

## 4. 価格と収益

### 販売価格
| 人数 | 価格 |
|---|---|
| **1〜4名** | **¥60,000／組** |
| 5〜6名 | ¥75,000／組 |
| 7名以上 | 要相談（+¥8,000／人） |

> 市場実勢は¥128,000〜145,000／組（4-5名・**専用車両＋ホテル送迎込み**）。
> **車両なしの電車ベースなので¥60,000は妥当かつ競争力がある。**

### 収益試算（4名・拝観料込みの場合）
| 項目 | 金額 |
|---|---|
| 売上 | **¥60,000** |
| のりおりくん ¥800 × 5（客4＋ガイド） | ▲¥4,000 |
| 高徳院 ¥300 × 4 | ▲¥1,200 |
| 長谷寺 ¥400 × 4（★仮） | ▲¥1,600 |
| 江ノ島施設 ¥500 × 4（★仮） | ▲¥2,000 |
| 雑費・自分の交通費 | ▲¥1,200 |
| **原価計** | **▲¥10,000** |
| プラットフォーム手数料 25% | ▲¥15,000 |
| **粗利** | **¥35,000／日** |
| **（直販の場合）** | **¥50,000／日** |

> 💡 **拝観料を「込み」にすることを推奨。**
> 訪日客は各所で現金を出すのを嫌う。**All-inclusive の方が売れるし、レビューが良くなる。**
> 原価¥10,000は売価の17%に過ぎず、価格競争力を損なわない。

### 💰 月次の見込み
```
月8回稼働 × 粗利¥35,000 = 月28万円（プラットフォーム経由）
月8回稼働 × 粗利¥50,000 = 月40万円（直販）
```

**設備投資ゼロ・在庫ゼロ・船宿への依存ゼロで、この水準に届く。**

## 5. 運営上の注意

| 項目 | 内容 |
|---|---|
| 🚫 **送迎は絶対にしない** | **自家用車での有償送迎は白タクで違法**（道路運送法）。集合・解散は必ず駅 |
| ⚠️ **江ノ電の混雑** | 休日は積み残しが出るほど混む。**平日を推奨**し、休日は時間に余裕を持つ |
| ⚠️ **冬の閉門時間** | 大仏17:00／長谷寺16:30／報国寺受付16:00。**冬は逆算して組む** |
| ⚠️ **抹茶券は15:30まで** | 報国寺の抹茶を入れるなら午前〜昼に回す |
| ⚠️ **食事** | 昼食を含めるか明確にする。含めないなら事前告知 |
| ⭕ **参拝作法の説明** | 手水・二礼二拍手一礼は**訪日客が最も喜ぶコンテンツ**。必ず入れる |
| ⭕ **写真** | ガイドが撮る。**客が自分では撮れない構図**を狙う（客＋富士山、客＋江ノ電） |

## 8. 🎯 この商品を先に立ち上げる選択肢

> **船宿ヒアリング（A）の結果を待たずに、これだけ先に始められる。**

| 論点 | 評価 |
|---|---|
| 必要な提携先 | **なし**（船宿も飲食店も不要） |
| 初期投資 | **ほぼゼロ**（のりおりくん代のみ） |

```
① 鎌倉・江ノ島アテンドで先に売上とレビューを作る
```
