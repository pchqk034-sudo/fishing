## 1. ⚠️ 鎌倉高校前の現実：市が本気で対策している

**ここを知らずにガイドすると、地域の敵になる。**

### 鎌倉市が実施中の対策（実証実験）
| 対策 | 内容 |
|---|---|
| **AIカメラ** | **12台で人流解析**。次年度は6台に集約し、警備員配置と警察への情報提供に活用 |
| **交通誘導員** | **9月1日から平日にも配置**。車道・軌道内での撮影に注意喚起 |
| **看板設置** | 「車両の通行の妨げにならないように」「ポイ捨て禁止」「人の土地に勝手に立ち入らない」 |
| **🎯 公式撮影エリア** | **腰越ラッコ公園に撮影エリアを設置**し、撮影目的の観光客を誘導している |
| 多言語発信 | 日本語・英語・中国語でSNS・公式ガイドから呼びかけ |

### 💡 これは制約ではなく、**最大の差別化材料**

> 個人客は「どこで撮っていいか分からず」道路に出て怒られる。
> **あなたは市が指定した撮影エリアを知っていて、そこへ案内できる。**

```
❌ 個人客        → 道路上で撮影 → 警備員に注意される → 気まずい思い出
⭕ あなたのツアー → 公式エリアで安全に撮影 → 良い写真 + 地域に歓迎される
```

### ガイドとして徹底すること
- [ ] **軌道内・車道に絶対に立ち入らせない**
- [ ] **私有地に入らせない**（民家の敷地）
- [ ] **ゴミは全て持ち帰る**（ガイドがゴミ袋を持つ）
- [ ] **騒がない**（住宅地であることを事前に説明）
- [ ] 市の公式撮影エリアを第一候補にする

> ⭐ **茅ヶ崎在住の地元民として、ここは絶対に外さないこと。**
> 地域の評判は、長期的にこの事業の生命線になる。

## 4.5 🎎 和装オプション（＝「コスプレ遊覧船」の最小実装）

> [`I_コスプレ遊覧船の検討`](./I_コスプレ遊覧船の検討.md) の結論を、この商品に落とし込んだもの。
> **船を持たず、許認可も要らず、固定費ゼロで「和装＋遊覧船＋富士山」が成立する。**

### 🚫 大前提
**既存アニメ・ゲームキャラクターの衣装は、いかなる形でも使わない。**
マリカー事件で**5,000万円の賠償＋代表者個人の責任**が確定している。
**外国語サイトでの表示も不正競争行為と認定された**ため、英語ページも逃げ場にならない。
→ **和装（着物・浴衣・法被）またはオリジナル衣装のみ。**

```
和装で着付け  →  江ノ電で移動  →  鎌倉高校前で撮影
       →  べんてん丸（大人¥400・約7分）に乗船
```
