# B. 競合・相場調査レポート

> 調査日: 2026-09-17 ／ 目的: 「いくらで売れるか」「原価はいくらか」を実データで確定する

---

## 0. 最重要の発見：**販売チャネルで単価が2〜3倍変わる**

同じ「日本での釣り体験」でも、どこで売るかで取れる価格がまったく違う。

| 販売チャネル | 単価水準（1人あたり） | 主な客層 |
|---|---|---|
| 日本の国内向け予約サイト（ActivityJapan等） | **¥13,000〜20,000** | 日本人・在住外国人 |
| Viator / GetYourGuide | 商品により幅大（$22〜） | 訪日客（価格比較しやすい） |
| **FishingBooker（世界最大の釣りチャーター予約）** | **US$314〜（約¥46,000〜）** | **海外の釣り愛好家** |

> **結論：国内チャネルで売ってはいけない。**
> 狙うべきは「日本に釣りに来る海外のアングラー」であり、彼らは
> FishingBooker等で**最初から$300以上を想定して探している**。
> 同じサービスを国内サイトに出すと、単価が1/3になる。

| 出典 | 内容 | 価格 |
|---|---|---|
| [FishingBooker 日本](https://fishingbooker.com/destinations/country/jp) | 日本の釣りチャーター | **US$314〜／人** |
| [Viator 日本の釣りチャーター](https://www.viator.com/Japan-tours/Fishing-Charters-and-Tours/d16-g9-c33) | 日本の釣り体験 | $22〜（商品により幅大） |
| 東京湾インバウンド釣りツアー（競合実例） | 5名まで一括 | **¥75,000**（追加1名 ¥15,000） |
| 同上・釣った魚の調理 | 提携飲食店で調理 | 約¥3,000 |
| 東京湾プライベート船 | 2時間 | ¥70,000〜130,000／隻 |
| 東京湾プライベート船 | 3〜4時間 | ¥40,000〜130,000／隻 |

### 競合の状況
- 東京湾には既にインバウンド向け釣りツアー事業者が複数存在（`Tokyo Japan Fishing Guide`、`Amazing Tokyo Fishing Tour` 等）
- **ただし相模湾・湘南エリアはほぼ空白**
- 「ガイドHPが日本語のみのパターンがほとんどで、外国人からのガイドを受け付ける想定をしている方が少ない」（業界観測）

### ⚠️ 競合との差別化ポイント
東京湾勢は**シーバス・ハゼ・アジ等の小物**が中心。
**相模湾のキハダマグロ・カツオは、東京湾では絶対に提供できない商材。**
海外アングラーにとって「Tuna」は強力な訴求力を持つ（世界的に高単価魚種）。

## 3. 収益シミュレーション（2パターン比較）

**前提：** 売価 ¥46,000／人（FishingBooker水準 US$314）、プラットフォーム手数料25%

### パターン① 乗合ベース（4名）
| 項目 | 金額 |
|---|---|
| 売上 | ¥46,000 × 4名 = **¥184,000** |
| 原価：乗合 ¥14,000 × 4 | ▲¥56,000 |
| 原価：餌・氷・雑費 | ▲¥8,000 |
| プラットフォーム手数料 25% | ▲¥46,000 |
| **粗利** | **¥74,000／回** |

### パターン② 仕立てベース（6名・仕立¥150,000と仮定）
| 項目 | 金額 |
|---|---|
| 売上 | ¥46,000 × 6名 = **¥276,000** |
| 原価：仕立て（★仮定値） | ▲¥150,000 |
| 原価：餌・氷・雑費 | ▲¥15,000 |
| プラットフォーム手数料 25% | ▲¥69,000 |
| **粗利** | **¥42,000／回** |

### 示唆
- **少人数なら乗合の方が粗利が大きい。** 仕立ては6名以上揃って初めて有利になる
- ただし乗合には**「日本人客との相席」リスク**あり（言葉・マナー・釣り座の取り合い）
- **直販（自社サイト）なら手数料25%が丸ごと粗利になる**（パターン①で粗利¥120,000）

### 推奨する商品設計
| 商品 | 対象 | 船 | 理由 |
|---|---|---|---|
| **入門：アジ・マダイ・タチウオ** | 釣り初心者の訪日客 | 乗合 | 低原価・通年・失敗しにくい |
| **本命：キハダマグロ／カツオ** | 海外の経験者アングラー | **仕立て** | 高単価。初心者を乗合の本気マグロ船に入れると事故・トラブルの元 |

## 4. 鎌倉・江ノ島アテンド：相場

**当初の想定（¥40,000／組）は安すぎた。実勢はその2〜3倍。**

| 出典 | 内容 | 価格 |
|---|---|---|
| [鎌倉・江ノ島プライベートツアー](https://www.tripadvisor.com/Attractions-g303156-Activities-c42-t235-Kamakura_Kanagawa_Prefecture_Kanto.html) | 5名グループ | ¥29,000／人（計 **¥145,000**） |
| 同上 | 4名グループ | ¥32,000／人（計 **¥128,000**） |
| 同上 | 少人数 | ¥36,000／人 |
| [鎌倉・江ノ島 車付きプライベート](https://www.world-tourism.org/kamakura-and-enoshima-private-guided-day-tour-with-vehicle/) | 最大6名 | 約$491（**約¥73,000**） |
| [東京プライベートガイド相場](https://tanuki-tabi-travel.com/blog/tokyo-private-tour-guide-cost) | 1日 | **¥40,000〜80,000／組** |
| 同上 | 半日（3〜4時間）都内 | ¥40,000〜50,000／組 |

- 所要：フルデー約10時間
- 一般的な含有物：**専用車両・英語ガイド・ホテル送迎**・水・駐車場代（拝観料は別）
- 訪問先：大仏、長谷寺、鶴岡八幡宮、江ノ島
- **プラットフォーム手数料：20〜30%**

### 🚫 重大な制約：車両を自分で出せない
市場の高単価商品は**「専用車両＋ホテル送迎」込み**。
しかし**自家用車での有償送迎は白タクで違法**（道路運送法）。→ 2つの選択肢：

| 選択肢 | 内容 | 単価への影響 |
|---|---|---|
| **A. 電車ベース** | 江ノ電・湘南モノレールを使うツアー | ¥50,000〜80,000／組（車なしなら妥当） |
| **B. 提携** | 貸切バス・ハイヤー事業者と提携（合法） | ¥100,000以上を維持可能。ただし原価増 |

### 💡 電車ベースは「格下げ」ではない
**江ノ電そのものが観光資源。** 特に鎌倉高校前の踏切は
スラムダンクの聖地として海外（特にアジア圏）で絶大な人気。
「車で素通りする」より「江ノ電に乗る」方が体験価値が高い場面は多い。
→ **まずは電車ベースで開始し、原価ゼロで粗利を最大化するのが合理的。**

## 5. 結論と次の一手

### 確定したこと
1. ✅ **売価の天井は見えた** — 釣り：¥46,000／人（国際チャネル）、観光：¥73,000〜145,000／組
2. ✅ **相模湾・湘南のインバウンド釣りは競合がほぼいない**
3. ✅ **キハダマグロは東京湾勢が真似できない差別化商材**
4. ✅ **観光アテンドの想定単価を上方修正**（¥40,000 → ¥73,000〜）

### 未確定（→ ヒアリングAで潰す）
1. ❓ **相模湾の仕立て料金**（最大の原価変数）
2. ❓ **外国人客の受け入れ可否**（船宿側の意向）
3. ❓ レンタルタックルの有無・料金
4. ❓ 予約リードタイム・キャンセル規定

### チャネル戦略（優先順）
| 順位 | チャネル | 理由 |
|---|---|---|
| 1 | **FishingBooker** | 単価が最も高く、客層が「釣り目的の訪日客」と完全一致 |
| 2 | Viator / GetYourGuide / TripAdvisor | 観光アテンド側の集客に有効 |
| 3 | 自社英語サイト（直販） | 手数料ゼロ。実績とレビューが溜まってから移行 |

> ⚠️ 国内向け予約サイト（ActivityJapan等）は**単価を壊すので初期は使わない**。
