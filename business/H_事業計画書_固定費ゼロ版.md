| **強み** | 茅ヶ崎在住・実釣経験・船宿人脈・技術力／**富士山が見える海は相模湾だけ** |

> ### 🔑 この計画の設計思想
> **「儲かる形」ではなく「負けない形」から始める。**
> 固定費がゼロなら、客が来なくても、天候が荒れても、赤字にならない。
> だから**何度でも試せる**。試せる回数が多い方が、最後は勝つ。

## 10. リスクと撤退基準

| リスク | 対策 | 影響度 |
|---|---|---|
| **船宿の協力が得られない** | **①観光アテンド単独で事業が成立する**（[`F`](./F_鎌倉江ノ島アテンド設計.md) 第8章） | 🟡 致命的でない |
| 天候中止 | **観光への振替**を標準設計に | 🟢 対策済 |
| 釣果ゼロ | 富士山・調理・観光で満足度担保 | 🟢 対策済 |
| 船酔い | 半日・湾内寄り・酔い止め標準提供 | 🟡 |
| 事故 | 保険必須・同意書・安全ブリーフィング | 🔴 **最重要** |
| 旅行業法の該当 | **M1-M2で事前相談**。必要なら課金設計を変更 | 🟡 早期に潰す |
| インバウンド急減（為替・情勢） | 固定費ゼロなので**赤字にならない**。休止して待てる | 🟢 構造的に強い |
| 低評価レビュー | 通し稽古・少数精鋭・無理な受注をしない | 🔴 |
| 本業との両立 | 週15hを超えない。超えるなら本業化を判断 | 🟡 |

### 撤退・見直し基準
| 時点 | 基準 | 判断 |
|---|---|---|
| **6ヶ月** | 有料成約が**3件未満** | 🔴 商品・価格・チャネルを全面見直し |
| **12ヶ月** | 年間粗利が**50万円未満** | 🔴 撤退 or 事業内容を転換 |
| 随時 | レビュー平均が**4.3を下回る** | 🟡 受注を止めて品質を立て直す |
| 随時 | 累計投資が**60万円を超える** | 🟡 一旦停止して再評価 |

> 💡 **固定費ゼロなので「撤退」しても失うのは初期投資44万円のみ。**
> しかも**1級免許は資格として残り、鎌倉の知識も経験も消えない。**

## 11. 本業化の判断基準

**感覚で辞めない。条件で決める。**

- [ ] **月間営業利益が、本業の手取り月収を超えた**
- [ ] それが**6ヶ月連続**で続いている
- [ ] **生活費6ヶ月分**の貯蓄がある
- [ ] 年間稼働が**100回を超えている**
- [ ] レビュー平均 **4.8以上・50件以上**
- [ ] **委託できるガイドが1人以上確保できている**（自分が倒れても回る）

> **3年目の営業利益660万円**は、これらを満たした状態を想定している。

| やらないこと | 理由 |
|---|---|
| 🚫 **船を買わない** | 年44回を2年連続で超えるまで（[`D`](./D_自船保有の検討.md)） |
| 🚫 **店を持たない** | 提携店の貸切枠が足りなくなるまで（[`G`](./G_夜の飲食_自前居酒屋の検討.md)） |
| 🚫 **人を雇わない** | 固定人件費を持たない。**委託（変動費）のみ** |
| 🚫 **借金しない** | 自己資金の範囲でやる |
| 🚫 **自家用車で送迎しない** | 白タクで違法（道路運送法） |
| 🚫 **国内向け予約サイトに出さない** | 単価が1/3になる |
| 🚫 **釣果を保証しない** | 必ずトラブルになる |
| 🚫 **自分が釣った魚を売らない** | 法的にグレー（[`G`](./G_夜の飲食_自前居酒屋の検討.md) 第5章） |
| 🚫 **キャパを超えて受注しない** | レビューが崩れたら終わり |
| 🚫 **既存キャラのコスプレを使わない** | マリカー事件で5,000万円＋代表者個人責任（[`I`](./I_コスプレ遊覧船の検討.md)） |
| 🚫 **自前の遊覧船をやらない** | 船長と運航管理者の兼務禁止＝有資格者2名が必要（[`I`](./I_コスプレ遊覧船の検討.md)） |
| 🚫 **最初から自動化しない** | 手作業で売れることを確認してから |

## 14. まとめ：この計画の本質

```
  1年目  固定費ゼロで「売れる」ことを証明する        利益 108万円
    ↓
  2年目  回数を増やし、直販比率を上げる              利益 427万円
    ↓
  3年目  他人の時間を使い始める（委託ガイド）        利益 660万円
    ↓
  4年目〜 プラットフォーム化 / 自船 / 店舗を「利益で」買う
```

> ### 最も重要な一文
> **最初の3年間、固定費はゼロのまま。**
> だから、うまくいかなくても**負けない**。
> うまくいったら、**その利益で次の武器を買う。**
>
> 船も店も、**夢としては正しい。順番だけが間違いやすい。**
