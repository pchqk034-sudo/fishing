# A. 船宿ヒアリング質問票

> 目的: **「この事業が成立するか」を3〜5軒のヒアリングで判定する**
> 期間: W1-2（最優先タスク）
> 合格条件: **協力してくれる船宿が1軒以上**

---

## 0. このヒアリングの本質

これは価格調査ではない。**「パートナーが見つかるか」の検証**である。

判定したいのは次の3つだけ：

| # | 検証項目 | これが No なら |
|---|---|---|
| 1 | **外国人客を受け入れてくれるか** | 事業が成立しない（＝撤退または設計変更） |
| 2 | **仕立て料金はいくらか** | 粗利が計算できない |
| 3 | **継続的に組んでくれるか** | 単発で終わりスケールしない |

---

## 1. 事前準備

### 誰に聞くか（優先順）
1. **自分が実際に乗ったことがある船宿**（最優先。信頼関係が既にある）
2. 平塚・茅ヶ崎・大磯・腰越など、自宅から通える港の船宿
3. キハダ・カツオを出している船（差別化商材を持つ船）

> 候補は `data/boats.json` に46隻分あり。**神奈川23隻**から選ぶ。

### どう切り出すか
❌ **営業として行かない。** 「提案があります」は身構えられる。
✅ **客として行き、相談として聞く。**

> 「いつも乗せてもらってる○○です。実は、外国人の知り合いから
> 『日本で釣りをしたい』と言われることが増えてて。もし連れてきたら、
> 乗せてもらうことってできますかね？ちょっと相談させてください」

### 持ち物
- [ ] この質問票（印刷 or スマホ）
- [ ] メモ（その場で記録する。後回しにすると忘れる）
- [ ] 手土産（飲み物程度でよい。関係構築の投資）

### タイミング
- **出船直後〜帰港後の片付け中は避ける**（最も忙しい）
- 帰港後、客がはけた後の時間帯か、平日の出船がない日が狙い目

## 2. 質問票（優先度順）

### 🔴 最優先（これだけは必ず聞く）

**Q1. 外国人のお客さんって、これまで乗せたことありますか？**
- ねらい: 受け入れ実績と、生の感想（本音）を引き出す
- 追い質問: 「そのとき、どうでした？」「困ったことはありました？」
- ```
  記録: ____________________________________________
  ```

**Q2. 外国人客について、正直どう思われますか？ 不安な点は？**
- ねらい: **障壁の特定**。ここで出た不安が、自分が提供する価値になる
- 想定される回答: 言葉が通じない／マナー／釣り座／道具の扱い／事故／予約のドタキャン
- ```
  記録: ____________________________________________
  ```

**Q3. 仕立て（チャーター）だといくらですか？**
- ねらい: **最大の原価変数を確定する**
- 追い質問:
  - 魚種によって違いますか？（キハダ／マダイ／アジ）
  - 何名まで乗れますか？
  - 最低何名から出してもらえますか？
- ```
  仕立て料金: ¥__________ ／ 定員 ______名 ／ 最低 ______名
  魚種別の違い: ____________________________________
  ```

**Q4. もし私が通訳と引率を全部やるとしたら、受けてもらえますか？**
- ねらい: **クロージング質問。** ここでYesが取れれば検証成功
- 補足して伝えること:
  - 自分が同船して**全部面倒を見る**（言葉・マナー・道具・安全）
  - 船宿側の手間は**増やさない**
  - **ドタキャンさせない**（前金を取る設計にする）
- ```
  回答: ☐ Yes  ☐ 条件付きYes（条件: __________）  ☐ No（理由: __________）
  ```

## 3. 伝えるべきこと（こちらから提供する価値）

質問するだけでなく、**船宿にとっての利点を必ず伝える**。

| 船宿の不安 | こちらの提供価値 |
|---|---|
| 言葉が通じない | **自分が同船して全部通訳する** |
| マナーが不安 | **事前に日本のルールを教育してから連れて行く** |
| 事故が怖い | **保険に加入。同意書を取る** |
| ドタキャンされる | **前金制にする。自分が責任を持つ** |
| 手続きが面倒 | **予約・連絡はすべて自分が窓口になる** |
| 平日・閑散期が埋まらない | **訪日客は曜日を選ばない。空いてる日に入れられる** |

> 特に最後の「**閑散日を埋められる**」は船宿にとって実利が大きい。
> 「土日の混んでる日を取りに行くつもりはない」と明言すると警戒が解ける。

## 4. やってはいけないこと

- 🚫 **手数料の話を初回に持ち出さない** — まず関係を作る。金の話は2回目以降
- 🚫 **「ビジネスにしたい」と最初から言わない** — 警戒される。「知り合いを連れて行きたい」から始める
- 🚫 **複数の船宿を天秤にかけていると悟らせない** — 狭い業界。悪評は一瞬で回る
- 🚫 **その場で契約を求めない** — 「また相談させてください」で終える
- 🚫 **繁忙期の忙しい時間に行かない**

## 6. 判定基準（ヒアリング後の意思決定）

| 結果 | 判断 |
|---|---|
| **協力Yesが2軒以上** | ✅ **GO。** 商品設計（W3-4）へ進む |
| 協力Yesが1軒 | ⚠️ 進むが、その1軒に依存するリスクあり。追加で2〜3軒回る |
| 条件付きYesのみ | ⚠️ 条件を潰せるか検討。潰せるなら進む |
| **全てNo** | 🔴 **設計変更。** 下記「Noだったときの代替案」へ |

### Noだったときの代替案
1. **他エリアに広げる** — 東京湾側（既にインバウンド実績がある事業者が存在＝受け入れ土壌あり）
2. **観光アテンド単独で始める** — 鎌倉・江ノ島は船宿の協力が不要。先に収益を作ってから釣りに戻る
3. **自分で船を持つ** — 遊漁船業登録＋小型船舶免許が必要。時間と資金がかかるが参入障壁も高くなる

> ⚠️ ただし、**「全てNo」の可能性は低い**と見ている。
> 船宿にとって閑散日の売上は純増であり、言葉の問題を肩代わりしてくれる
> 日本人の常連客は、むしろ歓迎される立場にある。
