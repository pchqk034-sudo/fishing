# G. 夜の飲食：自前居酒屋の検討

> 作成日: 2026-09-17
> 問い: 昼は船＋観光アテンド、夜は自前の居酒屋でおもてなし——これはどうか

---

## 0. 結論

### ⭕ 「夜のおもてなし」という発想は**正しい**
### ❌ 「自前居酒屋」という手段は**今は間違い**

理由は3つ。**どれも単独で事業を殺せる。**

| # | 問題 | 深刻度 |
|---|---|---|
| 1 | **体が1つしかない**（昼と夜が物理的に衝突する） | 🔴 致命的 |
| 2 | **固定費ゼロという最大の強みを失う** | 🔴 致命的 |
| 3 | **ツアー客だけでは席が埋まらない**（試算で証明） | 🔴 致命的 |

> **ただし「夜に稼ぐ」こと自体は諦めなくていい。**
> **固定費ゼロのまま実現する方法がある**（→ 第5章）。

---

## 1. まず、発想が正しい理由

「夜」に着目したのは筋が良い。理由は明確。

| 効果 | 内容 |
|---|---|
| **客単価が伸びる** | 昼の¥38,000〜60,000に、夜の飲食が積み上がる |
| **体験が完結する** | 釣る → 食べる → 語る。**1日のストーリーが閉じる** |
| **提携先が不要になる** | 釣果調理の外注先を探さなくてよい |
| **滞在時間が伸びる＝記憶に残る** | レビューの質が上がる |
| **地域のハブになれる** | 長期的なブランド資産 |

**この方向性自体は、フェーズ3で本気で検討する価値がある。**
問題は**「今やること」ではない**という一点。

---

## 2. 🔴 問題①：体が1つしかない

```
昼: 08:30 集合 ─────────────────── 17:30 解散（船＋観光）
夜:                    17:00 仕込み ───────────── 24:00 片付け
                            ↑
                        完全に重なっている
```

### 現実
- 居酒屋は**仕込みから片付けまで**が仕事。夕方5時に店に入って終わりではない
- 船は早朝から。**前日の仕込み＋当日の早起き＋夜営業**は身体が持たない
- **週15時間の副業では、そもそも不可能**
- 本業化しても、**1人で昼ガイド＋夜居酒屋は持続不能**（数ヶ月で潰れる）

### 「人を雇えばいい」の落とし穴
人を雇う → **固定人件費が発生** → 問題②に直結する。
しかも「自分がいない居酒屋」は、**おもてなしの主体が自分でなくなる**。
当初の目的（自分がもてなす）を失う。

---

## 3. 🔴 問題②：固定費ゼロという最大の強みを失う

### 今のモデルの強さは「損をしない」こと

| 状況 | 現在（ガイド業） | 居酒屋を持つと |
|---|---|---|
| 客が来ない月 | **損失ゼロ** | 🔴 家賃・人件費が出ていく |
| 天候で中止 | **損失ゼロ** | 🔴 仕込んだ食材が無駄になる |
| 閑散期（キハダのない冬） | **損失ゼロ** | 🔴 固定費だけが積み上がる |
| インバウンドが減る外部ショック | **損失ゼロ** | 🔴 即座に赤字 |

> **これは「守り」の話ではなく、「攻め」の自由度の話。**
> 固定費がないから、価格を試せる。失敗できる。撤退できる。
> 固定費を背負った瞬間、**毎月の支払いに追われて実験ができなくなる。**

### 居酒屋の開業費用（実勢）

| 項目 | 金額 |
|---|---|
| **開業資金の相場（個人）** | **500万〜1,000万円** |
| 日本政策金融公庫 2024年度調査 | **平均985万円／中央値580万円** |
| 物件取得費 | 家賃の**6〜10ヶ月分** |
| 内装・外装 | 居抜き200万円〜／スケルトン500万円〜 |
| 厨房機器・設備 | 100万円〜 |
| 備品・消耗品 | 30万円〜 |
| **運転資金** | **固定費6ヶ月分＝約300万円** |

> ⚠️ **初期資金「月5万円以上も可」という前提から、2桁違う世界に入る。**

---

## 4. 🔴 問題③：ツアー客だけでは席が埋まらない

**これは感覚ではなく、計算で出る。**

### 送客できる人数
```
月8回のツアー × 4名 = 月32名
```

### 居酒屋の売上に換算
```
32名 × 客単価¥5,000 = 月16万円
```

### 対する固定費（湘南エリアの想定）
```
家賃 20〜40万円 + 人件費 + 光熱費 = 月40〜60万円
```

> ## 🔴 **月16万円の売上に対し、月40〜60万円の固定費。**
> ## **どう頑張っても足りない。**

### つまり何が起きるか
席の**7〜8割を地元客で埋める必要がある**。
→ 地元向けの集客・メニュー・営業が必要になる
→ **それはもう「普通の居酒屋経営」であって、インバウンド事業ではない**
→ 事業の主語が入れ替わる。**居酒屋が本業になり、ガイドが副業になる**

---

## 5. ⚠️ 法的論点：釣った魚を店で出せるか

**ここは想像以上にグレー。必ず確認が必要。**

| ケース | 評価 |
|---|---|
| **客が釣った魚を、その客に調理して出す**（持ち込み調理） | ⭕ 比較的クリア。ただし**店側の衛生管理責任**は残る。→ 現在の [`E`](./E_冬商品設計_FishingWithMtFuji.md) の設計はこれ |
| **自分（事業者）が釣った魚を、店で客に出す** | 🔴 **実質「販売」に当たる可能性が高い** |

### 根拠
- 食品衛生法上、食品を販売する場合は**都道府県知事の許可または届出**が必要
- **「業として」**（反復継続する意思がある）魚介類を販売する場合、**保健所への届出が必須**
- **無届で魚介類を販売すると、50万円以下の罰金**
- **JGFA（日本ゲームフィッシュ協会）が「意図せず釣魚の販売に関わってしまわないための注意喚起」を出している**ほど、業界で問題視されている論点
- モラル面でも「遊漁は遊びであり、対価に金銭を求めるべきでない」という規範が釣り人の間で共有されてきた

> ⚠️ **「自分で釣ったマグロを自分の店で出す」は、最も夢のある絵だが、
> 最も法的リスクが高い。** やるなら保健所への事前相談が絶対に必要。
>
> 💡 **現在の設計（客が釣った魚を客が食べる）を維持する方が、法的にはるかに安全。**

---

## 6. 💡 視点の転換：あなたの本当の強みは「送客力」

ここが本質。

> **飲食店の最大の悩みは「集客」。**
> **あなたはそれを解決できる側にいる。**

```
❌ 自前でやる
   → 飲食店の一番苦しい部分（集客・固定費・人繰り）を
     わざわざ自分で背負いに行く

⭕ 提携する
   → 集客できるという希少な武器を持って交渉する
   → 有利な条件を引き出せる立場にいる
```

**送客できる人間は、飲食店にとって喉から手が出るほど欲しい存在。**
自前でやるということは、**その優位を捨てて、相手の弱点を引き受ける**ということ。

---

## 7. ✅ 固定費ゼロで「夜のおもてなし」を実現する6つの方法

**目的（夜に稼ぐ・体験を完結させる）は諦めない。手段を変える。**

| # | 方法 | 固定費 | 実現性 | 内容 |
|---|---|---|---|---|
| **1** | **提携店の貸切枠を押さえる** | **ゼロ** | ⭐⭐⭐ | 週1〜2日・特定時間だけ貸切。**実質「自分の店」の体験**を作れる |
| **2** | **間借り営業（シェアキッチン）** | **極小** | ⭐⭐⭐ | 昼だけ営業の店の夜、または定休日を借りる。**固定費を変動費化できる** |
| **3** | **出張料理人と組む** | 小 | ⭐⭐ | 場所（古民家・レンタルスペース）は都度借りる |
| **4** | **港でのBBQ形式** | 小 | ⭐⭐ | 東京湾の競合が「港でBBQ約120分」を実施済み。**設備投資が小さい** |
| **5** | **提携店とレベニューシェア** | ゼロ | ⭐⭐⭐ | 送客した分の一部を還元してもらう。**交渉力はこちらにある** |
| **6** | 自宅での食事会 | 小 | ⚠️ | **飲食店営業許可の問題があり要注意**。安易にやらないこと |

### 🎯 最有力は「①貸切枠」＋「⑤レベニューシェア」

```
週1〜2日、提携店の夜を貸切で押さえる
        ↓
その日は「自分の店」として、自分がもてなす
        ↓
固定費はゼロ。客が来ない週は押さえなければいい
        ↓
実績が積み上がったら、押さえる日数を増やす
```

> ⭐ **これなら「夜のおもてなし」が今すぐ、リスクゼロで実現できる。**
> しかも**うまくいくかどうかを、金を使わずに検証できる。**

### 💡 間借り（②）の戦略的価値
**固定費を変動費に変えられる**のが決定的。
- ランチ営業のみの店、定休日のある店は実在する
- 「夜だけ・週2日」で借りれば、月数万円で済む場合がある
- **失敗しても撤退コストがほぼゼロ**

## 8. 段階的な道筋

| フェーズ | 夜の設計 | 固定費 |
|---|---|---|
| **1（今）** | **提携店に釣果を持ち込んで調理**（[`E`](./E_冬商品設計_FishingWithMtFuji.md) の設計） | ゼロ |
| **2（6-18ヶ月）** | **貸切枠 or 間借りで「自分の夜」を作る**。レベニューシェア交渉 | ほぼゼロ |
| **3（18ヶ月〜）** | 送客だけで席が埋まる実績が出たら、**初めて自前を検討** | — |

## 9. 🚦 では、いつなら「自前」がアリか

**感覚ではなく、条件で決める。**

### 自前居酒屋に進んでよい条件（全て満たすこと）

- [ ] **月の送客が100名を超えている**（＝月32名の3倍以上）
- [ ] **提携店の貸切枠が埋まって足りなくなっている**（＝需要が実証済み）
- [ ] **ガイド事業が本業化し、自分が現場に出なくても回る体制がある**
- [ ] **自己資金で1,000万円を用意でき、かつ失っても事業が死なない**
- [ ] **料理人を雇える**（自分が厨房に立つ前提にしない）
- [ ] **地元客で平日を埋める算段がある**

> ### 🔑 判断基準
> **「提携店の貸切枠が足りない」という贅沢な悩みが出るまでは、自前をやらない。**
>
> 逆に言えば、**その悩みが出たら、それは最高のGOサイン。**
> その時点では需要が実証され、資金も実績もある状態になっている。

## 10. まとめ

| 論点 | 評価 |
|---|---|
| 「夜のおもてなし」という発想 | **⭕ 正しい。追求する価値がある** |
| 今すぐ自前居酒屋をやる | **❌ 事業が死ぬ**（時間の衝突・固定費・客数不足） |
| 釣った魚を自店で出す | **⚠️ 法的にグレー**。保健所への事前相談が必須 |
| **推奨** | **⭕ 提携店の貸切枠 ＋ レベニューシェアから始める**（固定費ゼロ） |
| 将来の自前 | **⭕ 条件を満たしたら検討**（第9章のチェックリスト） |

> ### 最後に
> **固定費ゼロで月40〜50万円を稼ぐ事業**を作ってから、
> **その利益で居酒屋を買う**——この順番なら、失敗しても何も失わない。
>
> 逆の順番（先に店を持つ）だと、**1回の判断ミスで1,000万円が消える。**
