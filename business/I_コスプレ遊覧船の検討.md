# I. コスプレ遊覧船（湘南クルーズ）の検討

> 作成日: 2026-09-17
> 発案: 公道カート（マリカー型）に着想を得た、コスプレ＋江ノ島・湘南遊覧船＋撮影オプション

---

## 0. 結論：3層に分けて判断する

| 要素 | 判定 | 理由 |
|---|---|---|
| **① コスプレ＋撮影** | ⭕⭕ **今日から実行可能** | ただし**既存キャラは絶対NG**。和装なら既存エコシステムあり |
| **② 遊覧船（既存事業者と提携）** | ⭕ **中期的にアリ** | 許認可は相手が持つ。固定費ゼロ |
| **③ 遊覧船（自前で運航）** | 🔴 **現時点では不可能に近い** | 知床事故後の規制強化で**1人では物理的に運営できない** |

> ### 要点
> **「コスプレして湘南を遊覧して撮影」というアイデアの本質は、
> 船を持たなくても、今日から検証できる。**

## 1. 🚨 最重要警告：引用されたマリカー事業には判例がある

**あの事業は、任天堂に訴えられて敗訴しています。**

### 判決の経緯
| 審級 | 時期 | 結果 |
|---|---|---|
| 東京地裁 | 2018年9月27日 | **1,000万円**の支払い＋不正競争行為の差止 |
| **知財高裁** | 2019年5月30日 | **5,000万円に増額。さらに代表者個人の責任も認定** |
| 最高裁 | 2020年12月24日 | 上告不受理 → **5,000万円が確定** |

### 何が違法とされたか
1. **「マリカー」「MARICAR」という名称の使用**（著名表示冒用行為）
2. **利用者にマリオのコスチュームを貸与したこと** ← ⚠️ **ここが本件に直撃**
3. **外国語のウェブサイトでの表示も不正競争行為と認定** ← ⚠️ **インバウンド事業なら直撃**

> 🔴 **「コスプレを貸して客に着せて商売する」ことそのものが争点になり、負けた。**
> しかも**会社だけでなく代表者個人が責任を負った。**
> 英語サイトを作るインバウンド事業では、**海外向け表示も逃げ場にならない。**

### ✅ ではどうするか

| コスプレの種類 | 可否 |
|---|---|
| 🚫 既存アニメ・ゲームキャラクターの衣装 | **絶対にやらない**（著作権・商標・不正競争防止法） |
| 🚫 「〇〇風」と匂わせる名称・演出 | **やらない**（マリカー社はこれで負けた） |
| ⭕ **和装（着物・浴衣・法被）** | **問題なし。しかも既に市場が確立している** |
| ⭕ オリジナル衣装（海賊・漁師・大正ロマン・船長） | 問題なし |
| ⭕ 客の私物コスプレの持ち込み | 問題なし（貸与しない） |

> 💡 **和装が答え。** キャラクター物の代替ではなく、**むしろ訪日客にはこちらが本命。**
> 「日本でしかできない」体験としての訴求力は、キャラ物より上。

## 1.5 ❓「ストリートカートは今も営業している。ならいいのでは？」

**よくある疑問。結論から言うと「営業している」は事実だが、「だから大丈夫」は誤り。**

### 何が起きたのか（時系列）

| 時期 | 出来事 |
|---|---|
| 2018年9月 | 東京地裁で敗訴（1,000万円）。**それでも当時はマリオのコスチューム提供を続けていた** |
| — | 商号を**「株式会社マリカー」→「MARIモビリティ開発」**に変更 |
| **2020年1月29日** | **知財高裁の終局判決。「マリカー」等の標章使用禁止に加え、<br>🚨「キャラクターのコスチューム貸与の禁止」が命じられた** |
| 2020年12月24日 | 最高裁が上告を退け、**5,000万円が確定** |
| 現在 | **Street Kart** としてブランドを変えて営業継続 |

> 対象とされたキャラクター：**マリオ・ルイージ・クッパ・ヨッシー**

### ✅ つまり、こういうこと

```
❌ 禁止された  : 任天堂キャラクターのコスチューム貸与／「マリカー」の名称
⭕ 続けられた  : 公道カート事業そのもの／キャラクター以外の衣装
```

> **Street Kart が今も営業できているのは、
> 「任天堂のIPを外したから」であって、「コスプレが許されたから」ではない。**
>
> ⭐ **これは本検討の結論（和装・オリジナル衣装ならOK）を、そのまま裏付ける事例。**
> 彼らは**5,000万円を払って、その線引きを証明してくれた。**

> ⚠️ 現在 Street Kart がどの衣装を提供しているかは、本調査では直接確認できていない
> （公式サイトへのアクセス不可）。ただし**裁判所命令によりキャラクター衣装の貸与は禁止されている。**

---

### 🚨 そして「他社がやっているから大丈夫」は、最も危険な判断基準

知的財産のリスクは、**普通のリスクと性質が違う。**

| # | 理由 | 内容 |
|---|---|---|
| 1 | **見逃されている ≠ 適法** | 権利者が動いていないだけ。違法性は消えない |
| 2 | **🔴 成功した瞬間に訴えられる** | **小さいうちは放置され、目立った途端に来る。**<br>マリカー社もまさにこれ（人気が出てから提訴された） |
| 3 | **遡って請求される** | 「知らなかった」「他社もやっていた」は抗弁にならない。<br>**過去の売上全体が損害算定の対象になる** |
| 4 | **代表者個人に及ぶ** | マリカー事件では**代表者個人の責任まで認定された**。<br>法人を畳んでも逃げられない |

> ### 💀 最悪のシナリオ
> **事業が軌道に乗り、本業化した3年目に、権利者から通知が来る。**
> 過去3年分の売上を基に損害賠償を算定され、個人にも請求が及ぶ。
>
> **成功すればするほど、損害額が大きくなる。** これがIPリスクの本質。

---

### 🔗 さらに：プラットフォームが急所になる

本事業の販売チャネルは **Viator / GetYourGuide / Airbnb体験 / FishingBooker**。

```
権利者がプラットフォームに侵害申立て
        ↓
出品が即座に停止される（裁判を待たない）
        ↓
売上がゼロになる。レビューも実績も失う
```

> ⚠️ **裁判で争う以前に、事業が止まる。**
> しかも**レビュー（[`H`](./H_事業計画書_固定費ゼロ版.md) の最重要KPI）を失うダメージは、金銭より重い。**

| | キャラクター衣装 | **和装・オリジナル** |

| 適法性 | 🔴 違法（判例あり） | ⭕ 問題なし |
| プラットフォーム停止リスク | 🔴 常時あり | ⭕ なし |
| 成功時のリスク | 🔴 **成功するほど増大** | ⭕ なし |
| 訪日客への訴求 | 母国でも見られる | ⭕ **日本でしか着られない** |

> **そもそも、着物で鶴岡八幡宮を歩き、船から富士山を撮る——
> この画に、キャラクターの着ぐるみは要らない。**

## 1.6 ❓「貸与がダメなら、販売にすればいいのでは？」

**結論：🔴 NO。販売にすると、むしろリスクが一段階重くなる。**

> ⚠️ 以下は一般的な情報整理であり、法的助言ではない。
> **実行判断の前に必ず弁護士に相談すること。**

### 権利構造：何を侵害するかが変わる

| 行為 | 侵害しうる権利 |
|---|---|
| 無断で衣装を**作る** | **複製権**（著作権法21条）・翻案権 |
| 作ったものを**貸す** | 複製権 ＋ **貸与権**（26条の3） |
| 作ったものを**売る** | 複製権 ＋ **譲渡権**（26条の2） |
| ロゴ・エンブレムを付けて売る | ＋ **商標権侵害** |
| 権利者を想起させる営業 | ＋ **不正競争防止法**（著名表示冒用・混同惹起） |

> 🔑 **「貸与」が禁じられたのは、判決主文がそう命じたから。**
> **禁止の根拠は「貸すという行為形態」ではなく「他人のIPを無断で商業利用したこと」。**
> **売りに変えても、根拠はそのまま残る。**
>
> 実務上も「グッズを製作・販売する行為は営利目的であり、**複製権や譲渡権の侵害**となる」とされている。

---

### 🚨 決定的な違い：民事から**刑事**に上がる

| | マリカー事件 | 無許諾コスプレ衣装の製造販売 |
|---|---|---|
| 性質 | **民事**（損害賠償・差止） | **刑事事件になっている** |
| 帰結 | 5,000万円の賠償 | **逮捕・罰金** |
| 法定刑 | — | **10年以下の拘禁刑 または 1,000万円以下の罰金** |

### 実際の逮捕例
- **2014年**：『海賊戦隊ゴーカイジャー』のジャケット4点を著作権者の許可なく複製・販売したとして、
  **衣料品販売会社の役員が広島県警に逮捕**
- 『獣拳戦隊ゲキレンジャー』の衣装を無断複製・販売した個人が**逮捕され、著作権法違反で罰金刑**

> 🔴 **「貸与 → 販売」への変更は、民事リスクを刑事リスクに格上げする行為。**
> マリカー社は**お金で済んだ**。衣装の無断製造販売は**前科がつく世界。**

---

### ⚖️ 「実質で判断される」という原則

裁判所は**形式ではなく実態**で判断する。

```
「貸与が禁止されたから、販売の形にした」
        ↓
裁判所：「禁止を回避するためのスキームですね」
        ↓
🔴 悪質性が加重される（減軽ではなく）
```

**ツアー参加者に売って、その場で着せて、ツアー後に回収しない——**
これは**実質的に貸与と同じ**と評価される可能性が高い。
形を変えただけの回避策は、**むしろ心証を悪くする。**

---

### ✅ 唯一の合法ルートと、その現実性

**正規ライセンス品を、正規ルートで仕入れて売る**なら適法。
（著作権法上、一度適法に譲渡された著作物の再譲渡には**譲渡権が及ばない**＝消尽）

しかし事業として成立しない：

| 論点 | 問題 |
|---|---|
| **仕入コスト** | 正規ライセンス品は高い |
| **在庫リスク** | **物販になる＝[`H`](./H_事業計画書_固定費ゼロ版.md) の「固定費ゼロ」原則に真っ向から反する** |
| **サイズ・在庫管理** | 訪日客の体格に合う在庫を持つ必要がある |
| 🔴 **不正競争防止法は残る** | **衣装が正規品でも、「そのキャラクターの体験」を想起させる営業をすれば別途成立しうる。**<br>マリカー事件の本質は**「任天堂と関係があるかのような営業」**であり、衣装の入手経路とは別問題 |

> 🔑 **正規品を買っても、「マリオの格好で〇〇する体験」を売れば、
> 不正競争防止法のリスクは消えない。** ここが最も誤解されやすい点。

---

### 💼 事業判断として

**このスキームを検討している時点で、事業がグレーゾーン依存になっている。**

| 観点 | 評価 |
|---|---|
| [`H`](./H_事業計画書_固定費ゼロ版.md) の思想 | **「固定費ゼロ・負けない形」**。IPリスクはその真逆 |
| 物販在庫 | 固定費ゼロ原則に反する |
| 弁護士費用 | スキームの適法性確認だけで数十万円〜 |
| 期待リターン | **和装オプションと大差ない**（+¥10,000／人程度） |
| リスク | **刑事罰・前科・プラットフォーム永久停止** |

> ### 結論
> **同じ労力を和装に向けた方が、安全で、儲かって、訪日客にも刺さる。**
>
> リスクを取るなら、**取る価値のあるところで取る。**
> ここは、リスクに対してリターンが全く見合っていない。

### ⭕ 唯一問題のない形：**客の私物**
- 客が**自分で買って、自分で持ってきて、自分で着る** → 事業者は関与しない
- ⚠️ ただし**事業者側が「キャラ衣装で撮影できます」と宣伝した時点でアウト。**
  「衣装は各自ご用意ください」と受動的に留める分には問題が生じにくい

## 1.7 ❓「正規ライセンス品を正規ルートで仕入れて売る場合は？」

**（ディズニー／サンリオ／ワンピース／スラムダンク等を想定）**

> ⚠️ 一般的な情報整理であり法的助言ではない。実行前に必ず弁護士へ。

### まず、ご指摘は正しい：**論点が変わる**

| 行為 | 評価 |
|---|---|
| 正規品を仕入れて**売るだけ**（純粋な小売） | **⭕ 適法**（譲渡権・商標権は消尽する） |
| 正規品を**ツアーで客に着せる** | **🔴 別の問題が発生する** |

> 🔑 **ここが分岐点。**
> 問題は**「物の出所」ではなく「営業への使用」**。
> 正規品かどうかは、以下の論点に**一切影響しない。**

---

### 🔴 問題①：権利者が「商用利用」を明確に禁止している

これは推測ではなく、**権利者自身の公式見解**。

| 権利者 | 公式見解 |
|---|---|
| **サンリオ** | 商品の用途以外の利用や、**「集客・宣伝・勧誘を目的とした利用、商用での利用」はご遠慮いただいている**。加工して家庭内・友人など限られた範囲以外での利用も禁止 |
| **集英社**（ワンピース・スラムダンク） | **「個人の方に対してキャラクター・作品利用の許諾を行っていません」** |
| 一般原則 | 正規品のキャラクターグッズは**「個人利用に限る」**条件下にあることが多く、**商用利用・レンタル・営業使用は原則不可** |

> 🚨 **集英社は個人に許諾しない。**
> → **ワンピース・スラムダンクは、正規ルートを辿っても最初から不可能。**
> → 使いたければ**法人化して、実績を示して、ライセンス交渉するしかない。**

---

### 🔴 問題②：不正競争防止法は「衣装の出所」を問わない

**マリカー事件で認定されたのは、**
**「営業にキャラクターの標章とコスチュームを使用したこと」＝著名表示冒用行為。**

```
正規品を買う       →  適法
        ↓
それを着せてツアーを売る  →  「営業にキャラクターを使用」
        ↓
🔴 著名表示冒用行為（不競法2条1項2号）
   混同惹起行為（同1号）＝「公式ツアーだ」と誤認させる
```

> ⚠️ **混同惹起行為・著名表示冒用行為には、民事（差止・損害賠償）だけでなく刑事罰もある。**
> **衣装をどこで買ったかは、この成否に関係しない。**

---

### 🚨 問題③：鎌倉高校前 × スラムダンクは、最悪の組み合わせ

**ここが本件で最も危険。**

| 事実 | 意味 |
|---|---|
| 鎌倉高校前は**まさにスラムダンクの聖地** | そこでスラムダンク衣装のツアーを売れば、**「集英社公認の公式ツアー」と誤認される可能性が極めて高い** |
| = **混同惹起行為のど真ん中** | 「無関係だと分かるはず」という反論は通りにくい |
| 鎌倉市は**オーバーツーリズム対策の真っ最中**（AIカメラ・交通誘導員） | 権利者にとって**レピュテーションリスク**。<br>**「自社IPが地域トラブルの原因にされている」**状況は、**積極的に止めに来る動機になる** |

> 🔴 **権利者が最も嫌うのは、金銭的損害ではなくブランド毀損。**
> オーバーツーリズムで叩かれている場所で、自社キャラの衣装を着た団体が
> 写真を撮っている——**これは通報される前に権利者が動く類の話。**

---

### 💔 問題④：あなたの最大の資産を失う

[`F_鎌倉江ノ島アテンド設計`](./F_鎌倉江ノ島アテンド設計.md) で整理した通り、本事業の立ち位置は：

> **「無秩序な個人客」より「マナーを守らせる引率ツアー」の方が地域に歓迎される。**
> **茅ヶ崎在住の地元民であることが、参入の大義名分になる。**

**キャラクターコスプレツアーは、この立ち位置と正反対。**

```
地域が抑え込もうとしている現象を、商売として増幅させる
        ↓
地元での評判を失う（狭い地域社会。悪評は一瞬で回る）
        ↓
🔴 船宿・飲食店・レンタル店との提携基盤ごと崩れる
```

> ⚠️ **法的リスク以前に、事業の土台が壊れる。**
> 茅ヶ崎在住という**最大の資産**を、最も安く売り飛ばす選択になる。

---

### 💼 問題⑤：事業合理性も低い

| 論点 | 問題 |
|---|---|
| 仕入コスト | ディズニー等の正規衣装は高い |
| **在庫リスク** | 物販になる＝[`H`](./H_事業計画書_固定費ゼロ版.md) の**「固定費ゼロ」原則に反する** |
| サイズ | 訪日客の体格に合う在庫を揃える必要 |
| **景観のミスマッチ** | **富士山・鶴岡八幡宮・江ノ電に、ディズニー／サンリオの衣装は合わない**。<br>写真の訴求力はむしろ下がる |
| 客の動機 | 「ツアーのために1万円の衣装を買う」客がどれだけいるか |

---

### ✅ 唯一の正しい道：**公式ライセンスを取る**

**やるなら、正面から許諾を取る。**

| ステップ | 内容 |
|---|---|
| 1 | **法人化**（集英社は個人に許諾しない） |
| 2 | **実績を作る**（送客数・レビュー・地域との関係） |
| 3 | **権利者に企画を持ち込む**（または自治体×IPの公式コラボ枠に乗る） |
| 4 | ライセンス契約（最低保証金・ロイヤリティ・使用範囲の取り決め） |

> 💡 **鎌倉市とIPホルダーの公式コラボ企画が組まれる可能性はある。**
> **その枠組みに「地域の正規ガイド事業者」として入るのが、最も筋が良い。**
> → **[`H`](./H_事業計画書_固定費ゼロ版.md) の3年計画を完遂し、実績と法人格を持ってから。**

|---|---|
| 正規品を仕入れて売るのは適法か | **⭕ 小売行為としては適法**（消尽） |
| それをツアーで着せられるか | **🔴 NO。** 商用利用が権利者により禁止されている |
| 正規品なら不競法を回避できるか | **🔴 NO。** 衣装の出所は関係ない |
| ワンピース・スラムダンクは？ | **🔴 集英社は個人に許諾しない。交渉の入口にすら立てない** |
| 将来的には？ | **⭕ 法人化＋実績＋正式ライセンスなら可能**（3年目以降） |
| 今やるべきことは？ | **⭕ 和装。** 安全・高粗利・景観に合う・訪日客に刺さる |

> ### 結論
> **「正規品を買う」は、物の話。**
> **「営業に使う」は、権利の話。**
> **この2つは別問題であり、前者を満たしても後者は解決しない。**


## 2. 🔴 遊覧船を自前でやる場合の規制（知床事故後、激変した）

### 前提：遊覧船は「旅客船事業」であり、遊漁船とは別世界

| 項目 | 内容 |
|---|---|
| 根拠法 | **海上運送法** |
| 事業区分 | 遊覧船・屋形船 → **旅客不定期航路事業（許可制）** |
| 「旅客船」の定義 | **定員13名以上**の船舶 |
| 12名以下の場合 | 「人の運送をする不定期航路事業」→ **令和7年4月1日より届出制から登録制へ**（★詳細要確認） |
| 小型船舶（20トン未満）のみの事業 | 令和6年4月1日より**第2号許可**＝**事業許可更新制** |

### 🔴 知床事故（令和4年4月23日）を受けた規制強化

国土交通省は**66項目**の対策を実施。特に重いのが以下。

| 強化点 | 内容 |
|---|---|
| **安全統括管理者・運航管理者** | **令和5年5月から試験制度を開始**。資格者証には**試験合格＋所定の実務経験**が必要。**2年間の更新制** |
| **🚨 兼務の禁止** | **船長と運航管理者の兼務を原則禁止** |
| **安全管理規程** | 作成・届出・遵守義務。荒天時の運航中止基準・連絡体制・避難誘導方法まで具体化 |
| **船客傷害賠償責任保険** | 令和6年10月1日より限度額引上げ：**許可事業 3,000万円 → 1億円**／届出（登録）事業 3,000万円 → 5,000万円 |
| **救命設備** | 令和7年4月より**改良型救命いかだ等の搭載を義務化** |
| 監査・処分 | 強化 |

### 🚨 決定的な問題：**1人では物理的に運営できない**

```
船長と運航管理者の兼務が原則禁止
        ↓
最低でも「有資格者2名」が常に必要
        ↓
週15時間の副業では成立しない
        ↓
人を雇う = 固定人件費が発生
```

> **これは「頑張れば何とかなる」という種類の壁ではない。**
> 知床で26名が亡くなった事故を受けた制度設計であり、
> **小規模事業者の参入を意図的に難しくしている。**
